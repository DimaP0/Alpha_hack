# Проверка перед публикацией

## Обязательно заполнить

- [ ] Имена участников команды ALO.
- [ ] Контакт для связи.
- [ ] Публичная ссылка на репозиторий или архив исходников.
- [ ] Ссылка на развёрнутую демонстрацию или видео.
- [ ] Лицензия, если платформа требует её явно.
- [ ] Логотип/обложка в требуемом платформой размере.

## Перед записью видео

- [ ] Запустить Docker Desktop.
- [ ] Выполнить `docker compose up -d --wait`.
- [ ] Убедиться, что `http://localhost:8080/actuator/health` возвращает `UP`.
- [ ] Открыть приложение в окне не уже 1280 px.
- [ ] Использовать только тестовые аккаунты.
- [ ] Не показывать локальные системные окна, токены и файлы `.env`.

## Формулировки

- [ ] Говорить «сценарный финансовый движок» и «объяснимый алгоритмический скоринг».
- [ ] Не называть текущий модуль обученной нейросетью или моделью дефолта.
- [ ] Указать, что используются синтетические данные.
- [ ] Указать, что окончательное решение принимает сотрудник банка.
- [ ] Указать, что выдача средств имитируется.
- [ ] Не утверждать, что проект подключён к банковским системам.

## Техническая проверка

```bash
./scripts/verify-compose.sh
```

Ожидаемый результат: все этапы завершаются сообщением `passed`, а четыре основных сервиса остаются `healthy`.
