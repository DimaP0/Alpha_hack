# Пакет подачи — ALO

Готовые материалы для размещения проекта на хакатонной платформе.

## Что использовать

- `ALO.pdf` — основной файл для загрузки на платформу.
- `ALO.pptx` — редактируемая версия презентации.
- `PLATFORM_TEXT.md` — тексты для карточки проекта и полей формы.
- `DEMO_SCRIPT.md` — сценарий выступления на 3–5 минут.
- `TECHNICAL_NOTE.md` — архитектура, алгоритмы, надёжность и ограничения.
- `SCREENSHOTS.md` — порядок кадров и готовые подписи.
- `CHECKLIST.md` — что проверить перед публикацией.

В корне проекта также подготовлены:

- `ALO_SOURCE.zip` — архив исходников без сборочных каталогов и секретов.
- `ALO_SUBMISSION.zip` — единый пакет с PDF, PPTX, исходниками, текстами и отчётами проверки.

## Короткая формулировка

**ALO** — работающий кредитный конвейер для малого бизнеса. Предприниматель проверяет устойчивость плана в трёх сценариях, видит объяснимую оценку и подаёт заявку; сотрудник банка получает финансовый снимок, факторы риска и принимает окончательное решение.

Проект работает на синтетических данных. Скоринговый модуль реализован, проходит сквозные проверки и использует воспроизводимые формулы и объяснимые правила. Архитектура готова к подключению обучаемой модели после появления обезличенной исторической выборки. Проект не подключён к банковским системам и не является банковской офертой.
